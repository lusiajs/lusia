# Lusia logo

[Back to the project README](../README.md)

A cat-ear letter L with a curly tail. Black and white, with a white border.

| File | Use |
| ---- | --- |
| `logo.svg` | Main logo, scales to any size |
| `favicon.svg` | Browser tab icon (modern browsers) |
| `favicon.ico` | Browser tab icon (16, 32, 48, 64 px) |
| `apple-touch-icon.png` | iOS home screen icon (180 px, white background) |
| `logo-16.png` to `logo-1024.png` | Transparent PNGs in 16, 32, 48, 64, 128, 192, 256, 512 and 1024 px |
