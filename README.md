# Lusia

A UI framework for [Bun](https://bun.sh). You write each component as one `.lusia` file with TypeScript, HTML and SCSS. The page updates when your variables change.

> [!IMPORTANT]
> Lusia has no release yet. APIs and markup may change without notice.

## Quick start

You need [Bun](https://bun.sh) 1.4 or newer.

| Step | Command | What it does |
| ---- | ------- | ------------ |
| 1. Create an app | `bun create lusia my-app` | Makes a new folder with a starter app |
| 2. Install | `cd my-app && bun install` | Downloads the packages |
| 3. Run | `bun run dev` | Starts it at http://localhost:3000 |

To add Lusia to an existing project, run `bun add lusia`.
